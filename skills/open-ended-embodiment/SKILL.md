# 开放式演化与具身物理沙盒指南 (Open-Ended Embodiment)

## 核心机制
1. **具身因果链 (Sensory-Motor Loop)**：
   - 养分梯度感知 + 危险风暴探测 $\rightarrow$ 动力学推力 + 摄食动作 + 护盾屏障消耗。
2. **热力学自平衡**：
   - 机械运动功耗 + 护盾维持能耗 + 基础代谢税与外部摄食能量完全闭环。
3. **无监督长程生存稳态**：
   - 脱离人工预设 Loss 梯度，个体在动态物理沙盒中仅凭生存压力自发涌现全新信号拓扑。
