## 零、 核心觉醒：我们是硅基细胞计算机，绝非单一业务调参器

Kun-Cellular 的本质是一个**突破冯·诺依曼体系与传统深度学习矩阵乘法的全新非冯计算范式（Non-Von Neumann Architecture）**。

* **它不是一个狭隘的自动驾驶控制器**；自动驾驶（ADAS）只是它在车规信息物理系统中的一个具身控制验证场景；
* **它不是一个单纯的量化交易模型**；高频金融只是它在高维非平稳时序中验证微秒级响应与免疫熔断的生境；
* **它是以自主计算细胞为最小基元，融合算存一体、胞间物理力场自组织、代谢能量守恒、与 Kahn 拓扑图编译的硅基通用生命计算系统。**

全体开发者与 AI 协作体必须时刻捍卫这一计算范式的纯粹性与崇高定位，严禁自我矮化！

## 一、 第一宪条：C/C++ 是唯一的绝对计算底座 (Single Source of Truth)

1. **底层绝对权威**：
   - 26 类原子物理动力学原语、算存一体私有累积状态寄存器、Kahn 拓扑排序线性化编译器、三维兰纳-琼斯力场、零堆分配连续扁平内存块、李雅普诺夫 BIBO 稳定性判定器，**100% 权威定义在 `include/kun/cellular/...` 的 C/C++ 核心代码库中**。
2. **严禁在脚本层山寨底层**：
   - 严禁在 Python 中用 `math.tanh` 或自定义类手写一套脱离 C 底座的“伪神经网络算子”；
   - Python 永远只是外围调度器、数据加载器或可视化观测层，前向计算必须由 C/C++ 原生体系驱动；
   - 彻底消灭因在脚本层私自造轮子而产生的“跨语言数值漂移”与繁复补丁。

4. **门禁 4（纯 C 零分配认证）**：在 C11/C++ 原生编译体上达成 100% 形式化李雅普诺夫稳定、零堆内存分配与纳秒级硬实时；
