## U1. R0-R3 合并 — 双执行器对账迁移 (纯工程, 零新变量)

1. organism_adapter 导入冠军 bin → 新核心 RuntimeState 快照
2. 同一快照: legacy forward_nd vs reference executor vs optimized executor
   逐 tick 对账 (分数 + argmax 决策 + 内部记忆 + 延迟边语义)
3. 评测协议不变, 双执行器胜率等价 (配对 2000 局) → 此刻起新核心为主, legacy 为对照
4. 候选打分标记为 probe 语义 (为 U2 预接线)

**退出条件**: 对账零差异 (LegacyCompatible profile), 胜率等价区间含 0。

### U1 实证结果 (2026-09-08, commit d896332)
- ✅ 冠军(82细胞/425突触)冷迁移 → Reference/Compiled 双执行器 → **位级等价(逐细胞差=0)**,
  创世种子/3随机图/状态丰富图(延迟环+锁存+积分)全绿 (`tests/test_legacy_snapshot_reconcile.cpp`, 72/72)。
- ✅ 把关价值实证: 大模型(250细胞)**细胞ID重复(200/201)**被冷迁移拒收 → 按 legacy
  `id_to_idx` 后写覆盖语义删除死副本(Op_Sum/Op_Abs)修复为248细胞, tick1 即位级等价;
  随机图野端口/孤儿细胞被类型契约拒收(按设计)。
- ⚠️ **新核心语义差距(待底座演进)**: legacy forward_nd 是"测试时 K 步松弛收敛
  (默认 K=4, tol 1e-5, BIBO 钳制, α 阻尼混合) + 步内递归突触反馈"; 新核心执行器是
  单脉冲传播, `EdgeDelay` 仅 Immediate/PreviousTick。前馈/收敛图两者等价(冠军即此类),
  有环图(大模型, 2985突触含 recurrent 边)单步≠不动点。→ 需要新核心**松弛执行驱动器**
  (多步迭代 + 递归边步内反馈 + 收敛早停), 列入底座演进队列, 不阻塞 U2。
