## 四、冻结判据（主口径 = 未见 id 无塑）

记 `μ_E = mean_3(io_evo.un_id_nop)`，`μ_M = 0.3003`（前置冻结的 io_mix 三种子均值），`P = 0.0547`。

| 编号 | 假设 | 判据 |
|------|------|------|
| E1 | 打过持续性 | `μ_E − P ≥ +0.12` |
| E2 | 形态发生优于冻结结构化 | `μ_E − 0.1226 ≥ +0.08`（对照 = 既有 structured 长跑） |

| E5 | 拓扑真发生（非纯权重） | 每种子 `io_rewire_total ≥ POP × GENS`（平均每个体每代表型 ≥1 次 IO 重连事件） |

**可选强门（不过不判整体失败）**：`μ_E ≥ μ_M + 0.02` —— 演化 IO 显著优于一次性随机。

**阈值冻结声明**：上表在首跑启动前冻结；不足写 negative，禁止调阈值。

## 五、诚实条款

1. 本阶段不声称「可学习投影」若被误解为梯度学习；对外叙述必须用 **evolvable / morphogenetic IO axon rewiring**。
2. 用当前端点角色识别 IO 边：重连后「原效应器入边」可能不再指向效应器——这与 `io_mix` 同构，属配方性质，不是 bug；E5 以代际重连计数度量结构搜索强度（个体级初值对照因每个体独立发育种子而不可比）。
3. 不外推百万细胞；大规模仍走论文「微柱阵列」叙事，另开预注册。
4. 同协议 `io_mix` 单种子仅作当轮对照；E3 主比较对象是冻结的 μ_M。

### 6d. 阶段结论（负结果）

1. **代际 IO 轴突重连（本实现）未能复现一次性 `io_mix` 的未见分**；同协议下差约 **2.4×**。
2. 结构搜索确实发生（E5、递归边 ~12k），但选择压力下未收敛到与随机 IO 投影同级的有用接线；均值仅略高于既有 structured 长跑（0.123）。
3. **不调阈值**。论文对齐含义：形态发生算子「开了」≠「有效」；下一步若续攻，应另开预注册（例如：降低 IO 重连率 / 从 `io_mix` 初值再微调 / 受限邻域重连），**不得**把本负结果改写成通过。
4. 当前 FieldCML 塑关主口径默认发育配方仍保持 **`io_mix`（一次性联合随机）**。
