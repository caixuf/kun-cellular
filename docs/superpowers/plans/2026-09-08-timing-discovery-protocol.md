# 时序结构发现实验（预注册 — 底座开放结构发现能力判据）

## 命题

演化引擎能从**无时序结构**的胚胎中，通过 变异 → 表型差异 → 环境选择 →
知识固化 的闭环，**自发产生**可用的时序机制（状态原语），而非人工预置。

## 任务：延迟二选一（DMS, Delayed Match-to-Sample）

序列 10 拍：
- t0-2 样本期: in0 = ±1（样本方向）
- t3-7 延迟期: in0 = 0（无信息）
- t8 测试期: in1 = 1（脉冲）
- 判定: t9 时 ACT 通道 0 输出符号与样本方向一致 → 正确

**选择压力的本质**：t8-t9 时输入不含样本信息，纯代数图（无状态原语）
在信息论上不可能解决 → 正确率上限 ≈ 50-60%（靠 bias 猜）。
只有携带时序状态（EMA / DELAY_N / 滞回）的结构才可能存住 t0-2 的信息。

## 胚胎（无时序结构）

- 细胞: 受体 in0/in1 + OP_SUM + ACT_CHANNEL（纯代数，无状态原语）
- 种子: 随机扰动

## 演化循环（单线代际, G=12 代）

每代:
1. 出生（当前 germline）
2. 学习: probe 体 BPTT 拟合教师（代谢窗口含边权重 + 细胞参数——
   U2.3 教训: 分裂产生的出生基因必须可代谢）
3. 评测: DMS 正确率（环境选择压力）
4. 变异: 分裂提案 1 次, **变异池随机**: {OP_EMA, OP_DELAY_N, GATE_HYSTERESIS,
   OP_SUM} 各 25%（时序类型占 75%——变异池有多样性, 选择不随机）
5. 选择: 新形态正确率 > 旧 → 同化为下一代 germline; 否则回滚重变异
6. 付费建造（资源账本结算）, 灭绝不救

## 预注册判据

- **机制成立**: 代际序列中出现 ≥1 个时序状态原语细胞被选择保留,
  且最终正确率 ≥80%（纯代数对照 <65%）
- **对照 A（关键）**: 变异池换成纯代数 {OP_SUM, OP_SUB, OP_MULTIPLY},
  同预算同代数 → 正确率不得 ≥80%（否则说明改善与时序结构无关）
- **对照 B**: 固定胚胎无生长 + 同学习预算 → 正确率基线
- 结构账本如实输出: 每代保留/回滚的类型、付费、正确率
- 报告双榜: MECHANISM_STATUS（结构自发出现且被选择）/ DISCOVERY_STATUS
  （正确率提升量），分开写

## 位序纪律

BPTT 只是参数代谢工具; 被检验的本体是**结构变异与选择**。
学习曲线不是主指标; 主指标 = 时序原语的自发出现与保留。
