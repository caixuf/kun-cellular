## 1. 目标、预期能力与不承诺事项

**目标：让同一个参与计算的个体，其真实活动能够驱动资源变化、休眠、凋亡、分裂和突触重塑，并通过明确的遗传规则进入下一代。**

当前已经有真实结构编辑、Oja、资源生态和种群演化代码。本方案不是重新造一套原语，也不是把这些模块的存在当作完整生命闭环已经成立，而是补齐它们之间的身份、状态、因果和调度契约。

| 交付层次 | 实现并满足对应验收后可以声称 | 仍不能声称 |
|---|---|---|
| M1：同一个体的生命周期 | 实际计算活动影响资源；休眠改变执行；死亡删除真实节点；出生和增边进入真实计算图 | 生长一定提高任务表现、相关性等于贡献 |
| M2：发育与遗传闭环 | 子代继承先天图和发育规则；后天改变默认隔离；生命史可恢复、可追踪；存在真实选择链路 | 自然演化必然收敛、学到的所有经验都会遗传 |
| M3：通用能力实验 | 若相应实验通过，可分别声称在指定任务上实现资源适应、损伤后恢复或有用结构发现 | 通用智能、无限扩展、任意损伤均可恢复 |
| M4：业务与冻结交付 | 若对照通过，可声称在固定协议中改善斗地主等任务；支持范围内的成熟图可冻结部署 | 地主/农民必胜、胜率必升到某值、动态生长仍有冻结图的时延 |

**最有把握补齐的是机制完整性与可解释的演化过程，而不是某个胜率数字。** 结构变化增加搜索自由度，也可能使优化更困难。允许机制成立、任务收益不成立，并如实交付这个结果。

不做：无版本地修改原语数学定义、Python 重写前向、无关的全仓库重构、纯 C 在线变图、在线多线程热替换、无证据扩大细胞数量、将业务奖励字段放入底座。第 15-18 节授权规划的是与计算、生命周期、遗传直接相关的底座职责重构，不是业务代码借机改底座。

## 2. 用户已确认的默认语义

1. 旧的 `CellularOrganism::forward_nd()`、现有训练器和历史产物默认保持原行为。生命周期必须显式启用。
2. 新生命周期中的资源耗尽、休眠、死亡是真实事件。允许功能丢失和个体灭绝，不因成绩下降偷偷撤销死亡。
3. 非法结构编辑可以事务拒绝；“不利于任务”与“非法图”不是同一回事。
4. 子代默认继承先天图、初始参数和发育规则，不自动继承亲本后天结构、权重漂移、记忆、年龄、损伤、能量及优化器状态。
5. 后天结构/参数固化是独立、显式、可消融的模式。其语义是获得性改变的同化，不把直接复制后天权重混称为纯 Baldwin 效应。
6. Adam、Oja 与形态变化独立开关。梯度学习不是理论敌人，但不能代替结构生命周期。
7. 不默认锁定输入输出骨架，不设底座内的业务规模硬顶。有限主机资源由调用方显式配置和报告，不等于承诺无限内存。

## 4. 推荐架构：一个计算个体，三个时间尺度

```text
外围环境 / Task
  输入张量、局部资源供给、可观察扰动、终局评价
          |
          v
LivingOrganism
  germline: 先天图 + 发育规则
  phenotype: 唯一参与计算的表型，迁移前由 CellularOrganism 承载
  life_state: 与真实 cell/edge ID 绑定的资源、活动、年龄、损伤
          |
          +-- 快层：原生前向、原语状态、可选局部权重学习
          +-- 慢层：资源结算 -> 生命周期提案 -> 图事务 -> 状态迁移
          +-- 代际：环境评价 -> 亲本选择 -> 遗传变异 -> 新生个体
          |
          +-- 冻结：导出成熟 phenotype，停止生命周期
```

### 4.1 单一事实来源

- 每个个体只有一个权威计算表型。迁移前由 `CellularOrganism` 承载，迁移后由第 16 节的 `PhenotypeGraph` 与 `RuntimeState` 承载；旧对象只作适配，不双向维护两个可变权威副本。
- 生命周期 sidecar 只保存新增的能量、年龄、局部统计、事件和谱系；不重复维护第二份原语状态或突触权重。
- 细胞沿用稳定 `Cell::id`。边需要能区分平行突触的稳定身份，不能用 `(from,to)` 唯一定位。
- 新生 ID 单调分配；删节点后不复用；检查现有整数类型的溢出并显式失败，不使用 `cells.size()` 生成 ID。
- 新的 `LivingOrganism` 不暴露可任意改结构的可变引用。所有结构编辑经过同一个事务入口；现有静态 API 不因此被禁用。
- 首期只覆盖普通原语图。MLA/MoE/speculative 等嵌套对象若没有明确的深复制与状态迁移支持，应在 attach 时返回不支持，不能共享可变内部状态后假称隔离。

### 4.2 调度与观察/提交分离

每个真实环境步按固定顺序进行：

1. 接收本步已可观察的输入、资源和扰动；不读取未来标签或后续环境状态。
2. 执行当前表型一次，记录哪些细胞实际执行以及实际边传输。
3. 完成本步学习窗口的允许更新；确保没有未提交的反向 tape。
4. 按真实步数结算资源、损伤和活动统计。
5. 休眠/唤醒/死亡的执行状态在安全边界生效；死亡节点不能多运行一个周期。
6. 达到可配置的慢周期后，基于累计统计提出分裂、增边和剪枝。
7. 批量处理结构事件、编译一次、迁移状态、发布新 revision。

资源与死亡结算每个提交步执行；增长搜索可低频执行。周期、步长和随机种子写入运行配置，不能以墙钟时间隐式驱动生死。

候选打分、搜索和反事实探测属于 `probe`，不推进真实年龄、不消耗真实资源、不更新真实 Oja、不提交记忆。需要计量搜索开销时单独报告，不能混入个体生命钟。

### 4.3 三类重置

| 操作 | 必须保留 | 必须清除 |
|---|---|---|
| episode reset | 当前表型、live 权重、年龄、资源、生命周期累计统计 | 按任务契约清本局动态记忆和未完成学习窗口 |
| fork/probe | 复制全部当前状态到隔离分支 | 不改变真实个体，分支结束即丢弃 |
| spawn offspring | 先天图与规则及其显式变异结果 | 亲本后天记忆、资源、损伤、优化器、后天结构 |

不同环境试验之间，不能把同一训练个体跨独立样本继续适应，除非协议明确测量终生连续适应；独立 holdout 从同一锁定起点各自 fork。

## 5. 资源和局部发育规则

### 5.1 资源是建模量，不冒充硬件能耗

首期使用无量纲资源单位与逻辑 tick。不能将该账本直接称为焦耳、ATP 实测或真实 CPU 功耗。

对细胞 i，每步计算：

```text
activity_i = bounded_measure(actual output / configured activity scale)
cost_i = maintenance(state_i) * dt
       + execution_cost(type_i) * executed_count_i
       + transmission_cost * actual_transmission_measure_i
       + paid_repair_cost_i

energy_i(next) = energy_i + absorbed_i - paid_cost_i
```

`bounded_measure`、尺度和类型成本是明确配置。首个版本不把输出幅值当奖励，不默认把“活跃”解释为“有用”。延迟/抑制/稀有事件检测细胞不能仅因一段时间输出零被宣布无价值。

同一隔室的营养竞争从同一份快照计算需求，供给不足时按明确的比例规则分配，再统一扣账；禁止按 vector 遍历顺序先到先得。任何限幅都进入拒绝/耗散账本，不能凭空增加或抹掉资源。

资源守恒账：

```text
cell_energy + environmental_resource + structural_reserve
  + cumulative_dissipation + cumulative_export
= initial_total + cumulative_external_injection
```

结构生成要支付建造费用与子细胞启动资源；死亡回收从已有结构储备和残余资源转移，不能固定赠送“尸体营养”而没有对应扣账。毒性/损伤另记账，不混作能量。

### 5.2 状态与生死

- ACTIVE：执行原语、可参与可塑性。
- DORMANT：跳过原语与相关可塑性，输出为零，保留可恢复内部记忆；收取低维护费。进入休眠时处理循环输出，禁止残留旧信号持续驱动下游。
- 唤醒：恢复执行，迟滞阈值与最短停留时间均为显式配置。
- APOPTOTIC：终止执行、清除相关信号、回收有账可查的资源，在边界删除真实节点及关联边。
- 全部死亡时返回明确的 `Extinct`。缺失某个 Task 必需通道由外围契约判为不可用/失败，不默默回退教师或重建原图。

自然死亡不能因为断开输出被撤销。编译器的“空图合法”与“任务个体还能生存”必须分开判断。

### 5.3 首期局部结构策略

| 操作 | 首期触发证据 | 编辑行为 |
|---|---|---|
| 分裂 | 亲本资源有结余、局部应变/负载达到配置条件、冷却完成 | 在明确选中的因果边上插入细胞，扣建造与启动资源 |
| 增边 | 空间邻域内候选，实际活动的时序统计或局部可观察信号，资源足够 | 提出指定 source/target/port 的边；拒绝重复、非法端口等不合法提案 |
| 突触回收 | 经过成熟宽限期，使用量与维护成本满足规则 | 删除真实边并更新索引，不仅把权重置零 |
| 细胞凋亡 | 能量耗尽或累积损伤达到规则 | 删除真实节点，允许个体性能下降 |

现有随机/空间变异作为显式探索分支保留，以便与活动引导比较；不能取消探索后宣称孤立胚胎必然靠相关性接通。未接通节点的活动相关性可能根本不可观测，必须报告这个限制。

原语类型从统一的已有类型与参数初始化策略中选择，不固定只出生积分细胞，也不随机写入对该类型无效的离散通道/延迟参数。局部误差只能来自当前可观察信息；首期不假设可以把终局奖励精确分配给每个细胞。

不做全节点对全节点的相关矩阵。复用空间邻域能力，按调用方配置的提案工作预算采样；事件记录与代价必须可见。该预算限制每次搜索工作量，不是底座细胞总数硬顶。

## 6. 图事务、状态迁移和学习契约

### 6.1 首期选择同步安全边界

不做并发热交换。前向与反向结束后，使用候选图副本应用一批事件，校验后替换。慢层允许分配和编译；这不属于冻结前向的零分配承诺。

每个事件记录：逻辑步、事件 ID、cell/edge ID、原因、原始统计、资源转移、父子关系、旧/新图 revision、提交或拒绝原因。

同一批事件的顺序固定：已发生死亡的清理、其它删除、出生、增边。针对已死亡对象的后续提案标为失效并报告。非法增长事务不影响已结算的自然死亡；代谢扣账不能因增长编译失败整体回滚。

增长成本在候选事务中预留，只有图编辑成功才正式转账；失败必须释放预留，不得既扣出生费又没有子细胞。计算错误、编译错误和资源不足分别记录，不使用统一的成功型返回值掩盖失败。

### 6.2 存活状态按身份迁移

保留未改变类型的存活细胞的主状态、辅助状态、delay buffer/index、latch、上一输入与上一输出；不能按新 vector 下标迁移。休眠对象还需保留其冻结记忆。

保留存活边的 live weight、germline weight 与可塑性参数；新边有独立初始化规则。Oja 的 compiled 权重先通过明确 source-index 映射同步，不能让 compile 把它们重置。

新核心的编译不能把 live weight 重新定义成 `initial_weight`。该契约在 R2-R3 通过独立状态所有权落实，不在 R0 向旧 `compile()` 继续叠加保留模式。旧路径的已知缺陷要记录；迁移不能据旧 compiled 缓存反向覆盖源 germline。

现有编译器会推导循环边，因此新增节点可能改变旧边的时序解释。首期要求：存活边原有即时/延迟语义不被无声改变；不能保持时拒绝该增长提案并记录。无操作重编译、保存恢复必须重建相同执行顺序与反馈语义。若当前编译器无法满足，先以独立通用编译修复阻断推进，不通过清空所有记忆掩盖问题。

### 6.3 梯度与拓扑分开

- 一个学习窗口绑定一个图 revision。
- tape 未消费时不允许发布新图；请求要么延至窗口边界，要么显式取消窗口并记账。
- 首期在变图后统一重置该个体的 Adam moments 与步数，并报告重置次数；不冒险按下标复用。
- 同规模重连也要使旧 tape/梯度失效。
- 每个个体有独立优化器。不同个体不能因尺寸相同共享 moments。
- 权重学习、Oja 和生命周期的先后顺序固定；首个机制版本关闭 Adam/Oja，之后逐项启用。

完整持久化要包含使用中的优化器状态；如果尚未实现，只允许无优化器运行的精确续跑，并明确拒绝其它恢复模式。

## 7. 代际语义

`Germline` 保存出生模板、原语参数/初始边、发育规则参数及其版本。`Phenotype` 保存该个体一生形成的结构与 live 参数。

默认繁殖顺序：

```text
冻结评价 -> 选择亲本 -> 复制 germline -> 对 germline/发育规则做变异
  -> 校验 -> 初始化子代表型与新资源账 -> 从零开始一生
```

父代结构复杂不意味着子代默认复制复杂结构。先天模板可发生代际结构变异；生前结构变化则属于另一条路径。两者均记录清楚。

子代资源从外部出生预算或亲本/环境账户显式支付，不能每次复制免费创造能量。代际实验可以采用独立环境重置，但新环境的资源必须记入初始条件。

选择接口由外围提供任务表现、资源消耗和失败状态；不以内置“细胞越多分越高”充当自然选择。种群、评估、资源、结构提案使用独立 RNG 流，避免某个个体多生几次就改变其它个体的环境种子。

先交付单亲变异与选择。交叉繁殖不是两层生命周期成立的必要条件，首期不新增复杂交叉系统。后天同化作为独立开关，只能在明确边界修改 germline，并记录同化比例和内容。

## 9. 实施任务与依赖

每项遵循：先加入可失败的定向回归，再实现最小改动，运行该项相关目标，最后记录结果。此方案不授权自动提交；提交由执行者依用户指令处理。P0-P10 保留为能力与行为要求；采用重构路线时按第 17 节 R0-R7 排序落实，不先完整实现旧形态的 sidecar 再推倒重写。

### P0：锁定生命周期契约与静态对照

依赖：无。产物：配置类型、状态模型、实验 manifest、关闭模式回归。

1. 固定本方案的重置、probe、遗传、灭绝、资源单位和事件顺序。
2. 记录基线 SHA、编译器、配置、模型身份、随机种子和现有静态输出轨迹。
3. 定义 `Disabled / ObserveOnly / Active` 三种模式。Disabled 完全不建 sidecar；ObserveOnly 只记录，不影响输出、权重和原有随机序列。
4. 初始采用一个小型原生图，包含即时边、延迟边和有状态原语；不先使用斗地主冠军。
5. 新增 `tests/test_cellular_lifecycle_contract.cpp`。

验收：关闭模式与原调用相同；观察模式不改变计算结果；输入、配置非法时显式失败。此前工作的六门禁状态不自动继承。

### P1：身份、重编译和状态迁移

依赖：P0。产物：共享图编辑基础与 revision 契约。

1. attach 时校验重复 cell ID、悬空边、非法端口、参数有限性；不能只看 `compile()` 返回 true。
2. 添加能区分平行边的边身份 sidecar，以及 compiled 到原边的显式映射；所有编辑同步更新。
3. 抽取现有“指定边分裂、指定端点加边、删除边/节点”逻辑。随机选对象与实际编辑分离，旧演化方法调用相同编辑器。
4. 在 R2-R3 的新核心/迁移边界修复重编译丢 live 漂移、污染 initial baseline 的问题；不改变旧默认编译语义来假装已经兼容。
5. 保持存活节点记忆、循环语义和边权；新增对象初始化；删除对象不复用 ID。
6. 增加无操作重编译、删除前部元素、平行边、相同规模重连、循环图以及 ID 溢出回归。

验收：一次无操作重编译前后的后续状态序列等价；结构变更后存活对象的状态按身份正确继承；非法编辑不产生半提交图。

### P2：把真实计算活动接入资源账

依赖：P1。产物：可观察但尚不生死的实测资源闭环。

1. 在原生前向中提供仅新模式启用的执行控制/测量；测量必须知道是否执行及边传输的正确时间步，尤其循环边用的是上步输出。
2. 抽取现有稳态模型中适用的结算逻辑，输入实际活动而不是 ACTIVE 对应常数。
3. 统一能量、营养、结构储备、耗散和注入账；资源扣减不足时有明确的支付与耗尽语义。
4. 实现快照式隔室分配，保证改变细胞存储顺序不改变供给。
5. 生命周期活动统计独立于 `reset_state(false)` 清零的计数。
6. 新增 `tests/test_cellular_lifecycle_resources.cpp`。

数值 oracle：单节点初始资源 10、无补给、实际每 tick 成本 1，则 3 tick 后为 7；两节点总需求 4、隔室仅有 2，比例相等时各得 1；关闭活动成本项时，改变输出不影响该项扣账。

验收：至少 10,000 个确定性 tick 的资源守恒误差不超过 `1e-9 * max(1, cumulative_resource_scale)`；失败要定位账本，不调整阈值掩盖。该容差针对 double 资源账，不是所有前向输出的统一容差。

### P3：休眠、唤醒和真实死亡

依赖：P2。产物：资源状态真正影响原生执行与图。

1. 首期执行控制复用原有 dispatch；不复制任何原语方程。
2. 休眠跳过执行、清传输输出、保留内部记忆，关闭相关可塑性。
3. 配置迟滞与最短停留，防止资源临界处每步开关。
4. 死亡清理真实节点和所有关联边，并通过 P1 迁移其它节点状态。
5. 清理前后的快照记录资源回收，允许整体灭绝。
6. 新增 `tests/test_cellular_lifecycle_death.cpp`。

验收：相同图在充足/匮乏资源下出现不同执行行为；死亡节点不再出现在 compiled 图；存活 delay/hysteresis 状态不被清空；灭绝有明确状态，无教师或祖先图兜底。

### P4：分裂、突触生成和回收

依赖：P3。产物：M1 同一个体完整结构生命周期。

1. 实现局部活动统计、资源阈值、成熟宽限期和冷却。
2. 使用 P1 的指定对象编辑器，分裂必须实际支付成本，插入节点必须进入可解释的因果连接。
3. 复用空间邻域，支持活动引导与随机空间探索两个明确分支。
4. 对新增/删除边维护唯一身份和事件链；不把改权重误计为增边。
5. 默认原语初始化覆盖合法类型策略；接入 tripartite 时去掉隐式 `<64` 和固定积分细胞限制，兼容模式显式保留原策略。
6. 编译工作在慢边界批处理；自然死亡先提交，其余提案失败不撤销死亡。
7. 新增 `tests/test_cellular_lifecycle_growth.cpp`。

验收：有资源时可出生、无资源不免费出生；出生后新节点真实参与输出路径；删除事件影响真实计算；超过 64 个节点仍可按资源策略生长；没有配置在底座里的任务细胞数硬顶。

**M1 停止点：已经能声称“这张计算图会在一生中生长和死亡”，但不能声称“这样更聪明”。**

### P5：遗传、选择与学习窗口整合

依赖：P4。产物：先天/后天分离的代际闭环。

1. 加入独立 germline，与 phenotype 的所有权明确分开。
2. 子代从 germline 初始化；局部规则参数和先天图允许代际变异。
3. 外围 evaluator 产生表现和生存指标，复用现有选择流程，不使用细胞数量奖励作为默认目标。
4. 新个体独立 RNG 与优化器；结构、资源、评估随机流互不干扰。
5. 加入显式 assimilation 模式，默认关闭。
6. 逐项接 Oja、Adam；变图使 tape 失效，首期统一重置 Adam 并报告。
7. 新增 `tests/test_cellular_lifecycle_inheritance.cpp`。

验收：默认子代不带父代后天边/权重、资源或记忆；同化打开时只继承声明内容；发育规则突变在相同环境下可造成可追踪的不同发育事件；同尺寸重连不能复用旧梯度。

### P6：完整持久化、恢复与事件回放

依赖：P5。产物：可续跑的生命体，不只是可加载的静态图。

保存：germline、phenotype、所有原语动态状态、live/initial 权重、边身份、资源/环境账、年龄、冷却、规则、RNG 状态、学习状态、图 revision、执行语义及事件序号。

1. 新独立格式逐字段编码，不直接 dump 含 padding、指针或容器的 C++ struct。
2. 保留 float/double 必需精度，不使用旧离散通道量化格式承载完整生命史。
3. 检查版本、长度、计数、有限性、身份映射和配置兼容；截断或未知必需字段非零失败。
4. 保存先写同目录临时文件，完成后再发布；不覆盖已有实验产物。
5. 首期只承诺同一二进制/平台下的精确续跑。保存随机引擎及有缓存的分布对象状态，或使用明确无隐藏缓存的抽样映射；仅保存 seed 不足以续跑。跨编译器/平台确定性另行定义，不默认承诺位级一致。
6. checkpoint 只在安全边界生成，保证没有半提交事件；probe 不写入真实生命史。
7. 新增 `tests/test_cellular_lifecycle_checkpoint.cpp`。

验收：连续运行 1,000 tick 与运行 500 tick 后保存/恢复再运行 500 tick，事件序列、身份、资源和后续输出一致。随后覆盖生死、循环状态、平行边、同化关闭/开启和启用优化器的恢复。

### P7：通用能力与因果消融

依赖：P6。产物：M2/M3 的证据，而非漂亮生长动画。

复用现有 temporal memory 的任务与参考图，新增资源和损伤协议。由 C++ Task 生成输入和评价，所有模型前向使用底座。

| 实验 | 干预与对照 | 可报告能力 |
|---|---|---|
| 资源切换 | 相同个体、输入，充足 -> 稀缺 -> 恢复；比较生命周期关闭/开启 | 资源约束下的执行调节与结构调整 |
| 损伤恢复 | 删除预先规定的功能边；静态受损、生命周期、无损参考三组 | 若表现恢复，称指定损伤协议下的功能恢复 |
| 时序功能发现 | 延迟/迟滞任务；断开胚胎、随机连接、先天参考、演化群体 | 若独立样本达标，称发现了有用时序结构 |
| 遗传规则选择 | 固定起点与评估种子，仅允许规则/先天结构变异 | 若后代泛化改善，称规则参与了有效选择 |

固定消融组：

```text
A: 固定拓扑、参数学习
B: 仅代际结构演化
C: 仅个体内发育
D: 个体内发育 + 代际演化
E: 与 D 相同，但移除活动引导，使用匹配提案预算的随机结构变化
```

先比较 B/C/D/E 的无梯度版本，再将参数学习作为独立因子加入。不同组相同初始信息、环境样本和资源供给；分别报告前向调用、梯度更新、提案数、编译时间和总时间。不能因为某组试得更多就归因于算法更优。

默认开发实验至少 10 个预先声明的训练种子；每个训练种子有独立 holdout。推断以独立训练种子为单位，不把同一模型的数千 tick 当作数千次独立实验。

机制验收与能力晋升分开。先天手工参考的成功只能说明可表达，不是演化发现。实验程序必须输出独立的 `MECHANISM_STATUS` 与 `DISCOVERY_STATUS`；科学发现不达标不能被总的 CTest 绿色覆盖。

建议预注册的晋升要求：

- 资源适应：稀缺阶段实际资源消耗下降，同时任务保真度达到预先锁定的任务下限；只省电但不能工作不算成功。
- 损伤恢复：归一化恢复比例 `(post_recovery - damaged) / (undamaged - damaged)` 在有效样本上达到事先设定目标，报告未恢复与灭绝比例；分母不足的样本单列。
- 时序发现：使用已有 delay/hysteresis 任务标准；不降低标准来迁就演化结果。
- 方法收益：预先锁定一个主要比较（D 对 E），报告跨种子的配对效应和区间；其它消融用于解释，不挑最有利的一项当总成功。

数值目标在看实验结果前写入 manifest。未设目标的探索阶段不得事后包装成过门禁。

### P8：斗地主接入，保持纯 BC 对照

依赖：P7 的机制门禁通过；不要求先宣称通用收益成立。

1. 保留当前静态模型、数据和评测协议；新实验使用独立命令/输出路径。
2. 先使用相同起始图和参数、不改变输入维度，隔离生命周期因素；之后才单独比较胚胎起点。
3. 同一决策的全部候选从相同快照 probe，不能让枚举顺序改变记忆、资源和生长。
4. 首个候选兼容版本仍保留静态评分器的单决策记忆重置：选定候选后只提交该候选的一次执行与生命钟。后续若要跨局内记忆，另做显式时序编码消融，不能混入首个生命周期对比。
5. 记录 probe 计算成本，但候选数不能自动变成生命年龄或资源惩罚，除非另立测量协议。
6. 教师只用于离线标注/对照；终局得分不能作为细胞已经提前知道的信用信号。
7. 先做参数学习开关、生命周期开关的配对对照，再考虑混合 DAgger。

验收：候选排列不改变非 tie 选牌和已提交生命史；每次真实出牌只推进一次生命钟；缺失输出、灭绝或非法策略显式记录，不落入启发式兜底。

### P9：冻结导出与运行边界

依赖：P6；用于业务冠军时还依赖 P8 的协议。

1. 在显式成熟时点冻结当前 phenotype，不导出 germline 冒充实际策略。
2. 停止生命周期与在线权重学习，标明冷启动部署与当前状态续跑的差别。
3. 复用现有 C 导出/执行路径前，列出它支持的原语、通道、端口、循环和状态集合。
4. 不能表达的图明确拒绝导出；不得丢端口、量化损坏通道、跳过状态后假称等价。
5. 若当前 C 后端不具备需要的语义，记录独立的通用后端事项；本期不扩展为 C 在线生命周期。
6. 对支持子集进行序列级 C++/C 对账，之后才运行既有零分配与时延基准。

交付允许分开：完整 C++ 生命周期可完成，而某类 C 冻结导出暂时阻断。禁止为了“全完成”降低一致性要求。

### P10：论文和能力声明同步

依赖：P7；涉及业务/部署主张还依赖 P8/P9。

1. 中英文论文同步区分静态参数学习、代际结构搜索、个体发育、资源生态演示、完整闭环。
2. 同步撤回 README 已撤回的旧斗地主 82.5% 主张，不用新数字为旧实验背书。
3. 更正 NEAT 只演化权重的表述。
4. 每个能力主张关联配置、SHA、事件记录和独立结果；缺失的消融明确列出。
5. 不将候选 BC 的胜率、资源生死演示或冻结前向时延分别替代完整系统的证据。

## 12. 对称性理论的适用范围

隐藏单元置换和正齐次算子的尺度变换能产生等价参数化，但不保证优化必达好解。对称性复制的是同一个函数，不是增加不同的优秀策略。

本方案采用两项有限用途：

1. 对 DAG 做保持类型、端口、参数、状态和 I/O 绑定的重编号/存储重排等价性回归。
2. 演化多样性统计中区分身份变化、图结构变化、行为变化；仅 ID 变化不计为功能创新。

循环图还必须保持延迟边与执行语义；空间生长还必须保持坐标和环境绑定。完整生态等价性比前向输出等价性更强。

不能把 ReLU 尺度变换套给阈值、饱和、时延参数、膜动力学或资源成本。即使输出等价，内部幅值和耗费也可能不同。

哈希只能用于候选分组，不能以哈希相同证明任意图等价。首期不新增昂贵的通用图同构系统，更不以等价去重为理由删掉对资源适应有差异的个体。

## 13. 斗地主最新报告的独立裁决

用户报告：3,000 局候选覆盖 100%；33,773 样本上量化冲突率为 0，但重复组只覆盖 100 样本；座次完整/置零准确率与胜率相近；1,000 局里地主约 30、农民约 970。以下是下一轮开发实验建议，不把这些用户报告改写成独立复测结论。

### 13.1 冲突率为零不等于证明观测充分

绝大部分输入只出现一次，其条件标签冲突根本没有可估计样本。当前结果仅说明在少量重复且按当前键定义聚合的观测上未发现冲突。

后续要确认键包含决策所需的完整模型输入，或证明候选交互特征可由观测和动作唯一重建；不同量化尺度分开报告。合法隐藏状态替换/教师依赖路径审计，可用于寻找同观测不同标签的反例，但不能把非法牌局当反例。

因此，不应因为 `e_alias=0` 宣布“不是缺信息，只能怪容量”。

### 13.2 先解释微型集的 3 个失败样本

先锁定样本与图，记录所有候选分数、margin、CE、梯度、通道可达性、是否存在相同输入不同标签、候选语义和 tie。

32 条中 29 条正确仍未达到此前 95% 目标（至少要 31 条）。延长该微型实验或改变一个优化参数用于区分未收敛与表示受限；不得将随机加细胞同时换目标函数后归因于容量。

在失败样本上做同状态、不同动作、相同后续策略的配对续局诊断，判断错误是否高杠杆；它是离线分析，不给线上模型泄漏隐藏信息。

### 13.3 DAgger：先固定预算的比例网格，再考虑协同特化

保持原始教师样本池、同一个模型策略采集的 DAgger 池、相同初始化与相同更新次数，比较有效抽样比例 0/10/25/50%。混合比例是每次抽样概率，不是“追加文件后仍跑相同 epoch”。

固定样本顺序种子和每个源的抽样规则。主要比较固定 dev 实战，兼报共同静态 dev、DAgger-state dev、pass/非pass 和地主/农民分层。初筛后再跨训练种子复核。

从头训练与 warm-start 是另一个实验因子，不与比例混用。现有 `V5_TEACHER_DATA` 是追加数据接口，不等于已经控制了有效比例和更新预算。

暂不新增手工农民协同规则，也不因为总体准确率上涨就晋升模型。先看错在哪些角色/阶段，以及这些错误是否主导胜负。

### 13.4 农民差距与地主协议

970 局的单个胜率标准误约 1.6pp，不是两策略胜率差的标准误。若粗略按独立比例计算，差值标准误约 2.24pp；实际采用相同种子，应使用配对胜负不一致计数和差值区间，不能仅据此说显著或不显著。

地主 30 局的 63.3% vs 50% 不足以证明优势。主榜保留原 17.5 叫牌协议；另开固定地主、轮换座位、相同牌局的诊断榜，三座位结果按基础牌局聚类，不把相关对局当独立样本。

固定地主诊断不能替换主榜，也不能挑“三家都过叫牌阈值”的牌局改变目标分布。座次消融无增益只支持当前配方下该新增输入未显示收益，不证明协作与观测无关。

### 13.5 斗地主行动顺序

```text
补齐配对逐局记录 + 解释 3 个微型失败样本
  -> 固定更新预算的 DAgger 比例网格
  -> 错误按农民协作/阶段分层诊断
  -> 独立固定地主与轮换座位诊断
  -> 必要时另立表示/时序改动
```

这些工作可与通用生命周期设计独立推进，但不得把多个因素同时打开后将收益统称为“自然细胞能力”。

## 15. 重构决策：保留计算资产，重建状态与语义边界

### 15.1 三种方案的取舍

| 方案 | 代价与收益 | 裁决 |
|---|---|---|
| 原大对象上继续补生命周期字段 | 接入快，但图、遗传、编译缓存和运行态继续耦合 | 仅用于过渡，不作为最终架构 |
| 全部推倒，包括原语与工具链 | 易切断历史包袱，但引入大量新数值差异，丧失对照 | 不采用 |
| 语义先行、模块抽取、新旧双轨迁移 | 保留可靠原语，逐项消除隐式行为；迁移有明确退出条件 | 推荐路线 |

双轨是两种可选择的执行入口，不是一个个体同时维护两套可变状态。比较时从同一只读快照建立两个独立实例；正式运行时只选一个。

### 15.2 保留、抽取、替换与暂不接入

| 当前资产 | 重构动作 | 理由 |
|---|---|---|
| `ops.yaml`、`tools/gen_ops.py` | 保留并补充类型/端口/状态语义元数据 | 已有单一生成链，不再另造算子体系 |
| `sdsc_primitives.h`、VJP 和 CUDA 生成物 | 保留现有语义版本；扩展只能经生成链 | 旧模型数值兼容不是随意改公式 |
| `generated_ops.hpp` 完整 CellType dispatch | 抽取为跨后端可调用的完整细胞内核，保留 legacy 语义档案 | 解决额外 C++ 分支导致的后端语义分叉 |
| `cellular_genome.hpp` 的 Cell/Synapse/compile/forward | 分离图定义、运行状态、编译产物与执行器 | 大对象不再同时拥有所有职责 |
| 原生 BPTT/Adam | 保留数值能力，增加合法参数视图、revision 与个体绑定 | 不把梯度重写混入架构重构 |
| 图增删操作 | 抽取共用编辑器，选择策略与编辑动作分离 | 个体发育与代际变异使用同一合法图事务 |
| 资源稳态模型 | 复用适用的结算规则，改为显式输入与资源账 | 不再建立与计算图脱离的第二个“生命体” |
| 人口选择、谱系及已有任务 | 复用外围调度与评价，明确输入和产物 | 不以内置大图奖励代替任务选择 |
| 膜、形态素、空间力场 | 保留为可选机制，并声明其是否实际参与计算/发育 | 不要求所有实验支付全部生物模拟成本 |
| MLA/MoE/speculative、多岛屿、高维场 | 暂不接入新生命体；旧入口继续使用 | 先解决一个普通原语图的一生，防止首期范围失控 |

### 15.3 重构不能改变的研究边界

- 新架构不是“神经网络无效”的证明，也不保证形态演化优于固定图学习。
- 局部规则是可遗传的假设，必须与随机提案、固定图和仅代际演化比较。
- 第一版不承诺图灵完备性证明、硬件非冯实现、全局稳定性证明或任意规模可扩展性。
- 边界外业务仍只提供输入、环境资源与评价，不提供“这条边应连哪里”的底座后门。

## 16. 目标模块、数据所有权与兼容契约

### 16.1 拟新增核心文件

路径均相对于仓库根目录；文件尚未创建。小型类型可同文件组织，不能为了目录整齐制造无职责的空层。

| 路径 | 唯一职责 | 可依赖 | 不可依赖 |
|---|---|---|---|
| `include/kun/cellular/core/primitive_contract.hpp` | 类型、端口、参数类别、状态布局、语义版本 | 生成的原语元数据 | Task、训练器、种群 |
| `include/kun/cellular/core/graph_ir.hpp` | 稳定身份、类型化节点、带端口和延迟的边、图结构 | primitive contract | 活动资源、优化器 |
| `include/kun/cellular/core/runtime_state.hpp` | 原语私有状态、执行历史、live 参数 | graph identity、state layout | 父代选择、业务字段 |
| `include/kun/cellular/core/compiled_graph.hpp` | 不可变执行计划、索引映射、状态布局与支持特征 | graph IR | 可变权重、资源、germline |
| `include/kun/cellular/core/graph_compiler.hpp` | 校验、确定性调度、布局、显式时序 lowering | graph IR、compiled graph | 任务成绩、生死规则 |
| `include/kun/cellular/core/reference_executor.hpp` | 按规定语义执行，输出完整可追踪记录 | 统一细胞内核、图、状态 | 代际选择 |
| `include/kun/cellular/core/compiled_executor.hpp` | 按同样语义执行连续内存计划 | 统一细胞内核、compiled graph、runtime state | 改写图结构 |
| `include/kun/cellular/core/development.hpp` | 实测活动、资源更新、局部发育提案 | 图只读视图、life state、共享编辑器 | 未来标签、业务动作规则 |
| `include/kun/cellular/core/heredity.hpp` | germline、出生规则、同化、子代初始化 | 图模板、规则参数 | 复制亲本整份 runtime 的捷径 |
| `include/kun/cellular/legacy/organism_adapter.hpp` | 旧对象导入、旧入口兼容、能力拒绝 | 新核心、旧数据结构 | 新核心反向依赖此适配器 |
| `include/kun/cellular/sdsc_cell_kernel.h` | 完整 CellType 的 C 可调用内核；由已有工具生成 | C 原语、生成的参数/状态布局 | 图分配、生命周期 |

`cellular_lifecycle.hpp` 组合这些模块成为 `LivingOrganism`。既有生成器可以使用 Python，但它只生成 C/C++ 源码，不在 Python 中执行生产计算。完整细胞内核同时覆盖双端口语义与特殊状态原语；不是另写一份相似数学。

### 16.2 五种对象的所有权

```text
Germline
  出生图模板 + 初始参数 + DevelopmentRules + 语义版本
       |
       v
PhenotypeGraph                 RuntimeState
  当前节点/边/类型参数          当前记忆 + live 可学习参数
       |                           |
       +-------> CompiledGraph <---+
                   只读执行计划
                         |
                         v
                    LifeState
                资源 / 年龄 / 损伤 / 事件
```

- `CompiledGraph` 保存参数索引，不拥有第二份可修改的 live 权重。重编译只换执行计划，不从初始权重覆盖当前权重。
- `Germline` 与 phenotype 没有隐式双向同步。普通学习和恢复 checkpoint 不得修改 germline。
- `RuntimeState` 的初始化状态要与活动统计分开。不能因 `activation_count==0` 就永久把静默细胞当成“从未执行过”。
- 旧语义若依赖 activation_count 的特殊初始化，应标记为 legacy profile 原样兼容；新语义使用独立 initialized 标记，属于显式版本变更，不能悄悄替换旧模型。
- stable ID 用于身份，dense index 用于执行。多条平行边具有不同 edge ID。索引复用不能等同身份复活。
- copy checkpoint、fork probe、spawn offspring 是不同入口，各自按第 4.3 节契约执行。

### 16.3 类型和参数契约

现有 `param1/param2` 只留在 legacy 数据表示中。新接口至少区分：

| 参数 | 表示和行为 |
|---|---|
| 输入/输出通道 | 整数通道身份；不能进入梯度参数数组；越界是错误而非自动映射到 0 |
| delay 长度 | 正整数与明示的 state layout；超出该语义版本能力时拒绝，不静默截断 |
| EMA 系数、gain、阈值 | 带参数域的连续值；优化器读取可学习标记 |
| min/max 等模式 | 枚举；不能通过随意浮点舍入决定 |
| 运行记忆 | 不属于可遗传参数；从 genotype 导入时初始化，从 checkpoint 恢复时保留 |

由原语 schema 生成具名参数字段与 metadata。相同原语所有消费者使用同一个 schema。不得把 `CellType` 数量、底层 opcode 数量、可微算子数量混为一个“26/27/30”常量。

接口骨架中的身份与延迟类型固定如下；它们不是整个实现，实际 primitive 参数类型由 schema 生成：

```cpp
#include <cstdint>

namespace kun::core {
struct CellId { std::uint64_t value; };
struct EdgeId { std::uint64_t value; };
struct InputPort { std::uint32_t value; };
struct OutputPort { std::uint32_t value; };
enum class EdgeDelay : std::uint8_t { Immediate = 0, PreviousTick = 1 };
struct EdgeDefinition {
    EdgeId id;
    CellId source;
    OutputPort source_port;
    CellId target;
    InputPort target_port;
    EdgeDelay delay;
};
}
```

新内部身份使用 64 位；向旧 32 位接口导出必须检查能否表示，不能截断。首期边延迟显式支持 0/1 tick，多步延迟通过已有延迟原语表达；这是一项版本能力，不是把任意 delay 参数压成 1。

### 16.4 显式时间语义

一个提交步的定义：

1. 冻结本步开始时的运行状态和上一拍输出。
2. `PreviousTick` 边读取上一拍输出。
3. `Immediate` 边按其 DAG 拓扑读取本拍上游输出；零延迟环编译失败。
4. 每个实际执行细胞读取自己的旧状态，计算本拍输出与下一状态；其它细胞不直接读写它的私有状态。
5. 全部成功后统一提交下一状态与本拍输出；失败时报告具体节点，不以数值归零制造成功轨迹。

同层节点按稳定规则调度，端口的边归约顺序明确。新图不因为插入顺序或容器哈希迭代次序改变反馈语义。

旧图导入时，使用旧编译器实际执行顺序识别其真实即时/反馈边，并把该结果显式写入新 IR。不能仅凭保存文件中可能失真的 `is_recurrent` 猜测。如果无法复现旧执行语义，拒绝迁移并保留旧入口。

旧图存在的精度、饱和、非有限处理属于 legacy 数值档案；新 strict profile 对非法值显式失败。导入时记录 profile，不能以“更严格”为由无声改变历史行为。支持域内先证明兼容，域外行为单独版本化。

### 16.5 参考执行器与优化执行器

两者共享同一完整细胞内核，差别只在寻址、调度和数据布局。参考执行器使用易追踪的结构，优化执行器使用连续数组和预编译索引。

模型的数值类型及转换点必须明确：现有混合 double/float 路径先作为 legacy profile 保存；不能在“抽取代码”时顺便全改 float。跨后端比较按 profile 规定精度；不能仅比较最终 action，不看内部记忆。

完整 C 细胞内核可以先供 C++ 执行器调用，而不修改旧 C 导出 ABI。纯 C 整图部署仍按 P9 的支持矩阵进行；原语 C 化不等于所有图已能导出。

## 18. 重构后的能力、收益边界与迁移风险

### 18.1 能明确补齐的工程能力

|---|---|
| 通道号、连续增益、模式混在浮点参数里 | 参数类型和学习权限明确，离散字段不会被普通梯度或量化隐式改变 |
| 编译顺序参与推测循环边 | 边的时序显式表达，零延迟环明确失败 |
| live/initial/compiled 多份权重互相覆盖 | germline、live 参数和编译索引各司其职 |
| 变图按数组下标迁移状态 | 稳定身份迁移；存活记忆保留，旧梯度必然失效 |
| 保存、reset、复制和繁殖语义重叠 | 四类操作有独立入口与状态边界 |
| 生命模拟与真正计算图分离 | 资源与生死直接作用于当前计算表型 |
| 不同后端只对齐部分底层 opcode | 按完整 CellType、端口、状态和语义版本声明支持 |
| 用名称和总分判断自然演化 | 事件、图变化、行为变化和选择效应分别有证据 |

这些是工程目标，可通过具体契约交付。资源适应、自修复、有用结构发现和业务牌力属于研究能力，只有实验成立后才可以新增声明。

### 18.2 主要风险及处理

1. **重构混入公式改变。** 使用语义 profile 隔离；机械抽取与数值改进不能同批发布。
2. **兼容层成为第二个底座。** 每项职责明确唯一所有者；已迁移路径只转发，不双向同步两张 live 图。
3. **生成器和手写 C++ 特例继续分叉。** 完整 CellType 内核进入同一生成链，序列状态对账先于后端优化。
4. **新核心依赖旧大对象形成循环依赖。** core 不包含 legacy adapter；适配器单向依赖 core，旧外观通过适配入口访问。
5. **一口气迁移全部消费者。** 按普通图、小任务、生命周期、学习、业务、部署逐级推进；高级器官未适配时明确不支持。
6. **所谓兼容只是输出接近。** 还需比较参数身份、反馈延迟、内部记忆、资源与后续动作；不能仅比较最终胜率。
7. **无限期重构不回答科学问题。** R3 必须先形成独立可运行的小核心，R4 必须形成真实生死闭环，R6 必须交付包括失败在内的实验结果。

### 18.3 执行建议

先实施 **R0-R3：语义与状态内核**，把其作为独立可交付子项目；再实施 **R4-R5：生命周期与遗传**；最后实施 **R6-R7：能力实验与消费者迁移**。每个子项目有自己的停止条件，但仍共同维护本文件，不另起互相矛盾的总体方案。

相比原方案，这不是多补几个函数，而是把“计算定义、当前身体、记忆、发育、遗传”从所有权上分开。这样才可能在不依赖业务补丁的前提下，持续研究细胞生长是否形成有用计算。
