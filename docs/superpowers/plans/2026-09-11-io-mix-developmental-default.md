## 二、配方定义（冻结）

**`io_mix`**：列格结构化骨架（局部内部拓扑保留）→ 仅打乱受体出边与效应器入边（目标 ∈ 全体细胞）→ `ensure_active_closure`。

## 五、诚实条款

1. 多种子 n=3 只能锁「非单次运气」，不能替代大规模统计。
2. `io_mix` 仍含归纳偏置（结构化内部 + 锚点）；不得宣称「自发无偏置有机体」。
3. 规模探针细胞数仍远低于旧 T0 预注册 64K；只声称「中等规模可运行」。
4. 训练最佳与未见分报；塑开口径仅参考。

### 6d. 阶段结论

1. **`io_mix` 可作为 FieldCML2D 塑关主口径的 L1 默认发育配方**（M1–M4 全过；多种子无塌缩）。
2. 结构化对照确认增益来自 IO 混合，而非「多跑几代 structured」。
3. 规模可跑、不崩（S1），但未见分相对小网格均值略退（S2 负）；下一步不应回头美化结构化 DAG，宜探 **可学习 IO 投影 / 锚点选择**，或更长 GENS 的 n=128 复测（另开预注册）。
