## 一、 任务本质与理论极限对账

在连续 2D 空间迷宫导航中，智能体只拥有 4 维局部传感（前向、左侧、右侧测距，目标相对偏角），动作输出为 2 维连续推力与角速度。迷宫走廊深度达 8~15 格，死胡同普遍存在。

我们在 200 个全新独立随机种子（Seed `77000..77199`，训练集完全未触及）上进行了全工况终极对账：

### 全工况跨范式天梯榜 (Seed 77000..77199, 200 独立盲测，严格对应 `./build/train_maze_tripartite --eval-only`)

| 计算架构与范式 | 拓扑与参数规模 | 400 步严苛限时通关率 | 1200 步长程通关率 | 核心动力学机理与物理对账 |
| :--- | :--- | :--- | :--- | :--- |
| **BFS 全知势场教师 (Oracle)** | 全局 Dijkstra 最短路图 | **34.5%** (69/200) | **100.0%** (200/200) | **物理速度极限**：21×21 最短路径长达 120~220 格，受限于线速度上限，400 步内物理上无法走完长路径。 |
| **纯反应式原始祖先** | 11 细胞 / 无内态 ($\rho=0$) | **8.0%** (16/200) | **23.5%** (47/200) | **极限环死锁**：无内部状态导致面对深死胡同时产生两步振荡，76.5% 迷宫永久卡死在陷阱中。 |
| **1024 细胞 GPU 皮层演化** | 1024 细胞 (16 微柱 × 64) | **15.0%** (30/200) | **53.0%** (106/200) | **混沌储层记忆涌现**：循环突触涌现长程时空记忆，从 23.5% 跳升至 53.0%，但高熵噪声稀释了微弱相位。 |
| **三权分立内态记忆体** | **21 细胞 / 迟滞门控核** | **33.5%** (67/200) | **76.5%** (153/200) | **最小充分完备解**：迟滞比较器原生锁定双稳态，400 步实测 **33.5%**（4.2× 击穿祖先 8% 天花板，逼近 BFS 教师 34.5% 理论极值）；1200 步达到 **76.5%**（3.3× 祖先）。 |

> ⚠️ **关于 5500 步指标的科学去伪声明**：  
> 早期草稿曾出现过“5500 步 100% 全通”的叙事。在严格消融审查中证实：在 21×21 有限空间中，质点在 5500 步长周期内的布朗碰墙随机漫游平均首次到达时间（MFPT）天然小于 5000 步——实测表明，哪怕是将记忆自环权重彻底清零的纯反应式无记忆个体，给 5500 步也能达到 100% 撞入终点。因此，**5500 步指标属于被步数膨胀稀释的无效指标，已彻底废弃**。真正的科学区分度严格锁定在 **400 步严苛限时（33.5% vs 8.0%）** 与 **1200 步长程探索（76.5% vs 23.5%）**。

## 二、 核心破局：利用通用底座原语构筑双稳态工作记忆

在不改动底座任何一行代码的前提下，我们直接组合通用原语库中的标准算子：
- **`GATE_HYSTERESIS`（迟滞比较器，Opcode 25）**：利用施密特触发器特性，在进入死胡同触墙后翻转方向，并在离开死胡同前持续保持反向偏置；
- **`GATE_THRESHOLD`（阈值门控，Opcode 24）**：滤除直道中的微小侧向波动；
- **`OP_MULTIPLY`（增益调制，Opcode 15）**：动态调节转向阻尼。

该 20 细胞微型网络以无限高信噪比锁定了空间探索的决策对称性，从根本上终结了纯反应式网络在死胡同振荡的数学宿命。
