## 二、 两次独立回放执行协议

对照 ADAS Gate 5 采用两个完全解耦的皮层实例在确定性环境下跑满全时长并记录逐帧时序轨迹的标准：

1. **环境与数据流固定**：
   - 选取固定的未见物理保留测试种子（如 `seed = 50017`，对应未见迷宫拓扑与随机起点/终点）；
   - 设定硬上限步数 `max_steps = 250`（或 400 步满额）；
   - 启用法定测地方位观测器 `task.set_use_geodesic_bearing(true)`，消除欧氏反向梯度假死。
2. **实例独立加载与隔离推演**：
   - **Replay 1**：
     1. 从 `maze_navigation_champion.bin` 加载第一个生命体实例 `org1`，执行 `org1.compile()` 展开 CSR；
     2. 构建独立任务环境 `task1(11, 11, seed, max_steps, 0.15f)` 并 `task1.reset(seed)`；
     3. 强制重置内部动态记忆状态 `org1.reset_state(false)`；
     4. 逐帧读取 4 维感知 `[ray0, ray1, ray2, goal_bearing]`，执行 `acts = org1.forward(obs, false)`，推演 `task1.step_continuous(acts)`，并记录轨迹 `trace1` 直至 `res.done` 或超时。
   - **Replay 2**：
     1. 完全独立地重新从磁盘加载（或深拷贝）第二个生命体实例 `org2`，重新编译 CSR 并清空状态；
     2. 独立创建新环境实例 `task2` 并使用同一 `seed` 初始化；
     3. 在相同的感知流驱动下完成推演并记录轨迹 `trace2`。

## 三、 逐帧比对字段清单

对两次独立回放记录的逐帧序列 $A = \{a_t\}$ 与 $B = \{b_t\}$ 进行严格差分核对：

| 比对维度 | 字段名称 | 物理意义与提取路径 | 容差门限 ($\max \|\Delta\|$) |
| :--- | :--- | :--- | :---: |
| **时序长度** | `steps` | 逃逸总步数 / 序列长度 `len(trace)` | **完全绝对相等** (`len(A) == len(B)`) |
| **智能体坐标 X** | `agent.x` | 连续二维平面横坐标 `task.get_agent().x` | $< 1.0 \times 10^{-6}$ |
| **智能体坐标 Y** | `agent.y` | 连续二维平面纵坐标 `task.get_agent().y` | $< 1.0 \times 10^{-6}$ |
| **智能体航向角** | `agent.theta` | 智能体连续航向姿态角 `task.get_agent().theta` | $< 1.0 \times 10^{-6}$ |
| **驱动效应器** | `acts.positive_action` | 前向推进马达推力输出 | $< 1.0 \times 10^{-6}$ |
| **转向效应器** | `acts.negative_action` | 差动转向角速度驱动输出 | $< 1.0 \times 10^{-6}$ |

## 四、 成功断言判据 (Success Criteria)

回放测试必须同时满足以下 4 条硬性断言方可签署 Gate 5 PASS：

1. **有效完赛断言**：
   - 两次回放轨迹必须非空，且均达成合法完赛状态（在给定步数内成功脱困 `res.done == true`，或相同步数正常终止）；
2. **帧数严格一致**：
   - `assert(trace1.size() == trace2.size())`，不允许出现单帧漂移或提前/滞后终止；
3. **位级确定性零随机抖动**：
   - 最大位姿差分 $\max(|\Delta x|, |\Delta y|, |\Delta \theta|) < 1e-6$；
   - 最大控制量差分 $\max(|\Delta \text{pos}|, |\Delta \text{neg}|) < 1e-6$；
   - 证明 C++ 运行时完全不受未初始化内存、浮点累积误差、随机数残留状态或线程竞争影响。
4. **门禁声明边界**：
   - **本卡只签署 Gate 5 PASS**；
   - Gate 6 已另测：`tests/test_flow_maze_gate6_shadow.cpp`，见 `2026-09-15-maze-g6-card.md`。
