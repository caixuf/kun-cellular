## 2. 架构

| 项 | 值 |
|---|---|
| 共享储层 | 500 blocks × 2,000,000 cells / 6,000,000 syns = 1B / 3B |
| 每步 active | top-5 blocks = 10,000,000 cells = **1%** |
| 路由 | 每任务独立 4D 网格（500 桶） |
| 读出 | 每任务 × 每块 ridge：64 block features + 4 raw obs + bias = 69 维 |
| 采集 | 每任务 100 episodes 冠军轨迹 |
| 评测 | 每任务 20 held-out episodes |
| block bins | `/tmp/opencode/moe_blocks_1b_v2`（30 GB，本地） |

三任务观测/环境：

- **maze**：11×11，250 步，geodesic bearing；
- **cartpole**：`CartPoleBalanceTask`，300 步；
- **maglev**：`ZooMaglev`，200 步。

成功语义：maze 到达目标；cartpole/maglev 满步存活。

## 4. 解读 / 限制

**可以说的（E2 窄口径）**：
- 一个 1B cells / 3B syns 的共享储层，在 1% active 下，三任务都达到 champion −5pp 以内；
- 这是对 S1 三任务判据的满足（scaled form），不是单任务过拟合。

**限制**：
- block 权重是随机储层，未训练；只训练每任务读出 + 网格路由；
- maze 恰好 −5pp，压线；20 eval episodes，统计噪声约 ±11pp；
- 采集 100 episodes/task，样本量有限；
- 不是 full 1B backprop；不是多任务单读出（每任务独立读出）；
- 30 GB block bins 本地可复现，不入库。
