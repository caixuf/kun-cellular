## 二、实验钉死的禁区（不要再试，每条都有对照实验）

1. **离线结构变异对成熟打分器无正期望**（三轮对照）：
   插入 EMA/DELAY/SUM（流式/打乱、全图靶点、α 多样化、10ep）全部
   -2~-4pp。根因：离线快照拍间隔教师动作介入，不构成连续环境流；
   同局相邻拍间无信息增量（上轮出牌已静态编码于 unseen/控台特征）。
2. **纯 DouZero 受限数据训练 → 实战崩盘**：单步 61.5% 但 2000 局
   **38.5%**（过牌 62.4%，地主 16.4%）——DAgger 分布漂移。
   混合 α 或冠军起点微调是修复方向，但注意这只是"追平/逼近教师"。
3. **LR 教训**：129k 数据 + LR0.004 CE 发散（1.03→1.08）；LR0.002 OK
   （单步 61.5%）。
4. **数据协议**：打分器训练数据是独立决策快照；gid 已按局排列。
5. 每次 train_cand 会**覆盖** checkpoints/doudizhu_cand_scorer.bin —
   训练前必须备份，训练后 md5 对账。

## 三、主路径：在线 RL 战役（自发超越的唯一通道）

模仿的天花板 = 教师水平。要**超过**，学生必须获得教师给不了的信息
= 环境反馈的自我博弈（DouZero 的配方，也是用户进化闭环的终局形态）。

### 战役计划（预注册）

**M1 轨迹学习器**（runner 内逐局 BPTT）：
- P9 runner 改造：每局结束后，对该局全部决策做一次 BPTT 更新
  （目标 = 局胜负回报/优势加权，或先做最小版：用本局教师标注做
  流式 BC 轨迹学习——仍以自博弈轨迹逐步替换教师轨迹）
- 关键新增：**自博弈比例随胜率爬升**（学生轨迹替代教师轨迹的
  课程机制——DouZero 配方的最小版）
- 评测节拍：每 N 局跑 500 局 holdout 配对，防漂移回退

**M2 自博弈闭环**：
- 对手池 = 历史形态快照（每 500 局冻结一个），对局对手从池采样
- 胜率 vs 教师每 1000 局测一次，预注册判据见下

**M3 超越判定**（预注册）：
- ✅ 使命达成：2000 局胜率 Wilson95 下界 **>59.4%**（教师上界）
- ⚠️ 中间门：≥58.3%（教师点估计）即"逼近完成，超越进行中"
- ❌ 回退门：任意中间评测 <55% → 停止迭代回滚到最近冻结形态
- 过牌率回归 ~48% ±3%（漂移哨兵——38.5% 事故的征兆指标）

### 现实约束（如实）

- P9 runner 逐局学习 = CPU 单机，速度与 DouZero GPU 集群差数个量级；
  使命是"超过启发式教师"（59.4%），不是追 DouZero（21%→X）
- 在线学习的崩溃风险（策略退化/遗忘）靠 M2 对手池 + M3 回退门兜底
- 遗忘防治：轨迹数据保留教师局缓存（回放混合），比例自适应
