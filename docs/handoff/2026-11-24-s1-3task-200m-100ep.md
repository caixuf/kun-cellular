# Handoff — 200M 共享储层 + 100-episode 三任务 PASS（2026-11-24）

> 目标：在 100 held-out episodes 下，用共享储层 + 每任务 teacher 蒸馏，
> 满足 S1 三任务判据（agent ≥ champion −5pp）。
>
> 结论：**PASS**。
> 100 blocks × 2M = 200M 总参数；top-1 = 2M active = **1%**；combiner-topk=1。
> maze 98% vs 97%，cartpole 100% vs 100%，maglev 100% vs 98%。

---

## 1. 证据

```text
COMMAND:
./build/train_from_teacher --task <maze|cartpole|maglev> \
  --blocks 100 --cells 200000 --syns 600000 \
  --teacher-episodes 100 --eval-episodes 100 \
  --topk 1 --combiner-topk 1 \
  --block-dir /tmp/opencode/distill_blocks_200m \
  --out runs/distill_<task>_200m_c1_20261124.json

GATE: DISTILL PASS（每个任务）
```

| 任务 | Champion SR | Agent SR | Δ | 判定 |
|---|---:|---:|---:|---|
| maze | 0.97 | **0.98** | +0.01 | ✅ |
| cartpole | 1.00 | **1.00** | 0.00 | ✅ |
| maglev | 0.98 | **1.00** | +0.02 | ✅ |

- 三任务共享同一套 100 blocks × 2M = 200M cells 储层；
- 每任务独立 k-means 路由 + 每块 ridge 读出 + combiner（top-1 + raw obs）；
- 每步只执行 **1 个 2M 块 = 1% active**；
- 100 held-out episodes（种子 93000+），不是 20ep 小样本；
- 之前 1B/500 块的 `combiner-topk=5` 会引入坏专家，导致 cartpole/maglev FAIL；
  改成 **combiner-topk=1** 后三任务全 PASS。

---

## 2. 关键修复

| 配置 | CartPole（100ep） | Maglev（100ep） |
|---|---:|---:|
| 10M / 100×100k / combiner top-5 | 0.57 | 0.00 |
| 1B / 500×2M / combiner top-5 | 0.91 (20ep 曾 PASS) / 100ep 不稳 | 0 / 0 |
| **200M / 100×2M / combiner top-1** | **1.00** | **1.00** |

根因：top-5 简单平均会把未训练好的块动作平均进来；
top-1 选最近的块 + raw obs combiner 更稳。

## 3. 仍然失败的任务

| 任务 | Teacher | Agent（200M c1） | 说明 |

| rocket | 0.84 | 0.05 | 强非线性/推力饱和，线性 combiner 不够 |

所以：

- **S1 三任务（maze/cartpole/maglev）100ep PASS**；
- 可学习架构对一阶/线性 + 中等非线性域有效；
- 强非线性任务（rocket/thermal）仍需非线性头/更大容量。
