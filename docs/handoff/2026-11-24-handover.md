## 2. 最重要的新能力：`train_from_teacher`

### 契约

```cpp
// tools/train_from_teacher.cpp
struct TaskSpec {
    std::string name;
    std::string teacher;   // 任意 CellularOrganism checkpoint
    int max_steps;
    std::unique_ptr<EvolvableTask> (*make)(uint32_t seed);
};
```

新任务接入：

1. 写一个 `make_xxx(seed)`（环境工厂，实现 `EvolvableTask`）；
2. 在 `registry()` 加一行 `{name, teacher_path, max_steps, make_xxx}`；
3. 启动训练：
```bash
./build/train_from_teacher --task <name> \
  --blocks 100 --cells 200000 --syns 600000 \
  --teacher-episodes 100 --eval-episodes 100 \
  --topk 1 --combiner-topk 1 \
  --block-dir /tmp/opencode/distill_blocks_200m \
  --out runs/distill_<name>_<date>.json
```

管线：采老师轨迹 → k-means 路由 → 每块 ridge 读出 → combiner → 100 held-out episodes。
**不改 28 原语底座。**

## 6. 已知坑

1. **block bin CSR 语义**：`make_block` 以 `inc_*`（入边）保存，runtime 按出边解释；
   2M 块 BPTT 里需要交换 `from/to` 再 `compile()`，否则动作细胞没有祖先、`compiled_synapses=0`。
2. **2M 块 CPU 前向很慢**：三任务 100ep 曾超时；GPU 前向（`SdscCUDAGraph`）必须带
   `LD_LIBRARY_PATH=~/.local/lib/python3.12/site-packages/nvidia/cu13/lib`。
3. **top-5 简单平均不稳**：用 `combiner-topk=1`；top-5 只在 20ep 小样本“看起来 PASS”。
4. **maze 压线**：200M 三任务 maze 98/97（+1），1B 20ep 曾是 90/95（−5 压线）。
5. **大 bin 不入库**：30GB block dirs 在 `/tmp`；仓库只保留 1M bin + readout。

## 7. 下一步优先级

1. **rocket/thermal 非线性头**：小 MLP combiner（68→16→2）或任务专属 top-k + 非线性；
